# Zepto Data & AI Platform

This repository contains an end-to-end Data and AI platform developed as a single integrated project.

## Project Modules

1. **Data Pipeline (`/data_pipeline`)**
   - Web scraping
   - Data cleaning and transformation
   - SQLite database
   - SQL and pandas analysis

2. **Analytics Pipeline (`/analytics`)**
   - Titanic data profiling and cleaning
   - Exploratory Data Analysis (EDA)
   - Classification and regression
   - Model evaluation and comparison
   - Model pipeline serialization

3. **Support Assistant (`/support_assistant`)**
   - Zepto policy document ingestion
   - Local embeddings and ChromaDB
   - LangGraph-based query routing
   - FastAPI service
   - Docker containerization

## Repository Structure

All three modules are maintained in this single repository.
